# YouTube Trend Analyzer

## Project Overview
This project analyzes YouTube trending video data using Python and Data Analytics techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Trending Video Analysis
- Category-wise Insights
- Most Viewed Videos
- Likes vs Views Analysis
- Data Visualization

## Output
Visual insights and trend analysis of YouTube trending content.
